# Clínica Saúde & Bem-Estar

Sistema desenvolvido em Python para cadastro de pacientes.

## Funcionalidades

- Cadastrar pacientes
- Consultar pacientes
- Editar pacientes
- Excluir pacientes
- Calcular IMC automaticamente

## Tecnologias

- Python
- Tkinter
- SQLite

## Como executar

1. Instale o Python.
2. Execute o arquivo clinica.py.
3. O banco de dados será criado automaticamente.
